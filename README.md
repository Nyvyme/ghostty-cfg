# Nyvyme's Ghostty Config

Theme &mdash; Rose Pine with edited background and foreground colors to look
like QtCreator Dark.

Font &mdash; SauceCode Pro Nerd Font (but has commented options for other
fonts).

Cursor shader grabbed from
[this repository](https://github.com/KroneCorylus/ghostty-shader-playground)
(I don't remember which one).

## Keybinds
* `Shift + Ctrl + R` &mdash; reload config
* `Shift + Ctrl + H` &mdash; open new split in left
* `Shift + Ctrl + J` &mdash; open new split in down
* `Shift + Ctrl + K` &mdash; open new split in up
* `Shift + Ctrl + L` &mdash; open new split in right
* `Alt + Ctrl + H` &mdash; go to split in the left
* `Alt + Ctrl + L` &mdash; go to split in the right
